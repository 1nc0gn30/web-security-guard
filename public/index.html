📖 Web Security Defense-in-Depth Best Practices

Architectural principles for modern, zero-trust web application security.

1. CSP Level 3 & Strict Nonces

Avoid domain allowlists which are vulnerable to JSONP/CDN script bypasses. Rely on dynamic per-request cryptographic nonces with 'strict-dynamic'.

2. Complete Origin Isolation

Deploy COOP (same-origin), COEP (require-corp), and CORP (same-origin) to shield against Spectre side-channel attacks and unauthorized embedding.

3. Cookie Hardening (RFC 6265bis)

Enforce Secure; HttpOnly; SameSite=Lax (or Strict) on all session tokens. Use __Host- prefixes for highest origin binding.

4. Subresource Integrity (SRI)

Lock third-party CDN scripts and styles with cryptographic hashes (sha384-...) to prevent supply-chain compromises.

🔌 CLI Commands & Python SDK

Automate audits, SSL inspections, posture diffs, and project patches in your CI/CD pipelines.

CLI Quickstart

# 1. Audit any live site from terminal
web-sec-guard audit https://example.com --format json

# 2. Inspect TLS / SSL certificate & cipher suites
web-sec-guard ssl google.com --port 443

# 3. Compare security postures between two targets
web-sec-guard diff https://example.com https://google.com

# 4. 1-Click patch local project repository
web-sec-guard patch ./my-project --platform auto

# 5. Generate strict CSP policy
web-sec-guard csp --preset strict_nonce --export nextjs

# 6. Compute SRI hash for CDN script
web-sec-guard sri https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js

# 7. Launch Web Security Studio UI
web-sec-guard serve --port 8080 --open

Python SDK Integration

from web_security_guard import SecurityAuditEngine, CSPBuilderEngine, WCAGContrastEngine

# Run comprehensive security audit
audit = SecurityAuditEngine.fetch_and_audit("https://example.com")
print(f"Score: {audit['score']}/100 Grade: {audit['grade']}")

# Generate Level 3 CSP
csp = CSPBuilderEngine.generate({"preset": "strict_nonce"})
print(csp["csp"])

# Validate WCAG 2.2 color contrast
contrast = WCAGContrastEngine.evaluate("#1a73e8", "#ffffff")
print(f"Contrast Ratio: {contrast['ratio_formatted']}, AA Normal: {contrast['wcag_aa_normal']}")
